# VIKO Games 🎮

**Plataforma de juegos interactivos de decisiones y estrategia**

## Descripción

VIKO es una plataforma web dedicada a ofrecer juegos interactivos que desafían tu mente y tus decisiones. Cada juego está diseñado para entretenerte mientras pones a prueba tu capacidad de tomar decisiones rápidas y estratégicas.

### Lema
**"Usa tu elección, toma el camino correcto"**

---

## Juegos Disponibles 🕹️

1. **Corre y Decide** 🏃
   - Corre rápido y toma decisiones en el camino
   - Desafío: ¿Lograrás llegar al final?

2. **Decisiones en 10 Segundos** ⏱️
   - Tienes solo 10 segundos para tomar la decisión correcta
   - Desafío: Actúa rápido o perderás

3. **Mente Crítica** 🧠
   - Ejercita tu mente y demuestra tu pensamiento crítico
   - Desafío: ¿Quién tiene el control?

4. **Misión Galáctica** 🛸
   - Viaja por el espacio y toma decisiones al límite
   - Desafío: La galaxia te espera

5. **UFO Smash** 🛸
   - Destruye y defiéndete en este juego rápido y adictivo
   - Desafío: Rápido, preciso y adictivo

---

## Tecnología

- **Frontend:** HTML5, CSS3, JavaScript
- **Juegos:** Scratch (embebidos con iframes)
- **Hosting:** Vercel (GitHub Pages compatible)
- **SEO:** Optimizado para buscadores

## Cómo Usar

### Localmente
1. Clona el repositorio
2. Abre `index.html` en tu navegador
3. ¡A jugar!

### En Vercel
1. Conecta tu repositorio de GitHub a Vercel
2. Vercel automáticamente deployará tu web
3. Tu URL será: `viko-games.vercel.app`
